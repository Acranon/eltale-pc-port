# Frames for the 2D kinds (docs/renderer/NATIVE_DRAW.md, "2D"), same format as tests/render_frames.txt.
# tools/frame_test.py runs it after the other lists. Japanese is the default; ELTALE_LANG=en is the port's
# English (port/text/en_text.c, en_images.c), ELTALE_FONT=n one of the optional English fonts.
# title_en: the English title (the menu strip, the logo), the New Game window and the opening dialogue.
# font1..5: the opening dialogue in each optional English font.
# intro:    the intro's sprite script (no input), Japanese and English.
# save:     the title's Continue: the save menu over the battle-stuck save's Controller Pak (and English).
# compass:  the compass-spirit save in the field: the HUD with the compass.
# panel:    the battle-stuck save: the enemy name panel (225), the spell input (250), and English.
# menu_en:  the item menu, the pause menu's status and map pages in English.
# ending_en: the epilogue pages in English.
# items:    the item menu with icons (the "items" save: python tools/make_items_save.py), the first and the second
#           item highlighted (CI8 icons loaded as a 16-bit block from the game's own memory).
