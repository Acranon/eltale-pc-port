# The reference frames for the native renderer (docs/renderer/REFERENCE.md), used by tools/frame_test.py.
# One line per headless run:   name | run arguments | frames to dump
# Run arguments: NAME=VALUE sets an environment variable, @save=<dir> copies <saves>/<dir> (a quick save,
# not committed; default saves folder out/bugsaves) into the run's scratch ELTALE_DATA_DIR, the rest are
# eltale-p1 arguments (--headless --fast and --rom are added). Frame numbers are graphics tasks, as
# ELTALE_DUMP_IMAGE counts them.
#
# ng:     New Game (tests/title-new-game.input): title logo, title menu, the fade, the dialogue window
#         opening, the opening dialogue (Spirit King, candle flames).
# tour:   ELTALE_MAP_TOUR, 18 sub-areas, ~160 VIs after each arrival: maps 0/0 (throne room), 1/0, 2/0,
#         3/0, 5/0, 9/0, 11/0, 13/5, 16/3, 20/0, 22/10, 25/0, the fields 26/0, 26/2, 29/0, 30/5, then 34/0
#         and 35/0 (HUD, compass, fog, backdrops, billboards).
# ending: ELTALE_START_MODE=5: the epilogue pages (text over the picture, the sepia fade), credits over
#         the camera tour with the letterbox.
# battle: the battle-stuck save (tests/battle-stuck.input, ELTALE_BATTLE_LOG=2): the field, spells, the
#         enemy panel, terrain rings, a floating "Miss!".
# menu:   the battle-stuck save (tests/item-menu.input): the item menu, the pause menu's status page,
#         the page turn, the map page, the field with the compass.
